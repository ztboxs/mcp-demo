# 需求文档

## 介绍

面向 Python 的 MCP 压缩服务：提供工具将图片压缩到目标大小（默认 10 KB），保持宽高比例，输出非 webp（默认 JPEG），在白名单目录内操作，并返回可观测结果。

## 需求

### 需求 1 - 单图压缩到目标大小

**用户故事：** 作为用户，我希望把单张图片压缩到目标大小，保持比例，得到非 webp 输出。

#### 验收标准（需求 1）

1. When 用户提供允许路径内的单张图片且未指定目标大小时，the MCP 压缩工具 shall 输出 JPEG 文件（去除 EXIF）并使文件大小 ≤ 10 KB，保持原始宽高比。
2. While 用户提供自定义目标大小（字节数），when 调用压缩工具，the MCP 压缩工具 shall 尝试达到指定大小并返回实际大小与状态。
3. While 经多轮质量降低与按比例缩放后仍无法达到目标大小，when 完成处理，the MCP 压缩工具 shall 返回最佳努力版本并在响应中标记 status=partial 且包含原因。

### 需求 2 - 批量压缩

**用户故事：** 作为用户，我希望一次压缩多张图片，并获得每张的结果。

#### 验收标准（需求 2）

1. When 用户传入同一允许目录下的多张图片路径列表，the MCP 压缩工具 shall 逐张处理并返回每张的状态、输出路径、最终大小。
2. While 任意文件不符合支持格式（如 gif/webp 等超出允许列表），when 批量压缩，the MCP 压缩工具 shall 对该文件返回校验错误但不中断其他文件处理。

### 需求 3 - 目录与格式约束

**用户故事：** 作为用户，我希望工具只访问白名单目录，输出非 webp。

#### 验收标准（需求 3）

1. When 输入或输出路径不在预设 allowlist 中，the MCP 服务 shall 拒绝请求并返回路径校验错误。
2. When 输出文件生成，the MCP 压缩工具 shall 采用 JPEG 输出（可选支持 PNG，默认 JPEG）且不生成 webp。
3. When 压缩完成，the MCP 压缩工具 shall 去除 EXIF/元数据以减小体积。

### 需求 4 - 参数与结果可观测

**用户故事：** 作为用户，我希望清楚获知压缩前后信息。

#### 验收标准（需求 4）

1. When 压缩完成，the MCP 压缩工具 shall 返回原始大小、最终大小、压缩比例、是否命中目标、输出路径。
2. While 发生异常（格式不支持、文件不存在、输出目录不可写），when 返回结果，the MCP 压缩工具 shall 提供错误代码与可读信息。
